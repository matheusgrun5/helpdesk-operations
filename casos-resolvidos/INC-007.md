# INC-007 — Tela preta com computador ligado

**Data:** Agosto 2026  
**Analista:** Matheus Grun  
**Prioridade:** Alta  
**Status:** ✅ Resolvido  
**Tempo de resolução:** 18 minutos

---

## Relato do usuário

*"Meu computador liga normalmente, mas a tela está completamente preta. O computador parece estar funcionando — dá para ouvir o barulho do HD e o ventilador — mas não aparece nada na tela."*

---

## Diagnóstico

| Passo | Verificação | Resultado |
|-------|-------------|-----------|
| 1 | Verificado energia do monitor | Monitor ligado na energia — ok |
| 2 | Verificado cabo HDMI nas duas pontas | Cabo conectado — ok |
| 3 | Testadas outras entradas do monitor | Sem sinal em todas as entradas |
| 4 | Testado com outro monitor | Imagem apareceu normalmente |
| 5 | Conclusão | Defeito no monitor original |

---

## Solução aplicada

Defeito confirmado no monitor original — substituído temporariamente por monitor reserva disponível no estoque de TI.

Usuário voltou a trabalhar normalmente com o monitor substituto. Aberta ordem de serviço para envio do monitor com defeito para manutenção.

---

## Causa raiz

Defeito no monitor original — painel interno com falha causando tela preta mesmo com sinal de vídeo sendo enviado pelo computador.

---

## Lição aprendida

Testar com outro monitor é o passo mais rápido para isolar se o problema está no monitor ou no computador. Quando a imagem aparece com outro monitor o diagnóstico é imediato. A solução de contorno — substituição temporária — é fundamental para restaurar o trabalho do usuário sem aguardar a manutenção do equipamento com defeito.

---

## Ação pendente

Monitor com defeito encaminhado para manutenção pelo N2. Aguardando laudo técnico para definir reparo ou substituição definitiva.
