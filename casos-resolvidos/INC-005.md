# INC-005 — BSOD ao ligar o computador

**Data:** Agosto 2026  
**Analista:** Matheus Grun  
**Prioridade:** Alta  
**Status:** ✅ Monitorando  
**Tempo de resolução:** Em acompanhamento

---

## Relato do usuário

*"Fui ligar meu computador hoje de manhã e apareceu uma tela azul com um erro. Desliguei e liguei novamente e entrou normal, mas estou com medo que aconteça de novo."*

---

## Diagnóstico

| Passo | Verificação | Resultado |
|-------|-------------|-----------|
| 1 | Perguntado o código de erro exibido | Usuário não anotou o código |
| 2 | Visualizador de Eventos — `eventvwr` | Erro crítico registrado no horário do BSOD |
| 3 | Código identificado nos logs | DRIVER_IRQL_NOT_LESS_OR_EQUAL |
| 4 | Computador reiniciado normalmente | Sistema entrou sem erros |
| 5 | Monitoramento iniciado | Chamado mantido em aberto |

---

## Solução aplicada

BSOD identificado como relacionado a driver — código DRIVER_IRQL_NOT_LESS_OR_EQUAL. Como o computador entrou normalmente após o reinício foi iniciado monitoramento para verificar recorrência.

Chamado mantido em aberto. Usuário orientado a anotar qualquer novo código de erro caso o BSOD se repita.

---

## Causa raiz

Driver corrompido ou incompatível — possivelmente causado por atualização recente do Windows ou instalação de software.

---

## Lição aprendida

Quando o BSOD ocorre uma única vez e o computador entra normalmente após o reinício — monitorar antes de tomar qualquer ação mais invasiva. O Visualizador de Eventos é fundamental para identificar o código de erro mesmo quando o usuário não anotou a tela azul. Chamados de BSOD nunca devem ser encerrados sem período de monitoramento.

---

## Ação pendente

Se o BSOD se repetir — escalar para N2 para análise aprofundada do driver e possível reinstalação do Windows.
