# INC-002 — Sites não abrem mas sistemas internos funcionam

**Data:** Agosto 2026  
**Analista:** Matheus Grun  
**Prioridade:** Média  
**Status:** ✅ Resolvido  
**Tempo de resolução:** 8 minutos

---

## Relato do usuário

*"Consigo acessar os sistemas internos da empresa normalmente, mas nenhum site abre no navegador. Tentei no Chrome e no Edge e o mesmo problema acontece nos dois."*

---

## Diagnóstico

| Passo | Comando | Resultado |
|-------|---------|-----------|
| 1 | Sistemas internos funcionam | IP e rede local ok — descartado problema de conectividade |
| 2 | `ping 8.8.8.8` | Resposta recebida — internet ativa |
| 3 | `ping google.com` | Tempo limite esgotado — DNS com falha |
| 4 | `ipconfig /flushdns` | Cache DNS limpo |
| 5 | `ping google.com` | Resposta recebida — DNS normalizado |

---

## Solução aplicada

Problema identificado no DNS — cache corrompido impedindo a resolução de nomes de sites. Executado `ipconfig /flushdns` para limpar o cache DNS local.

Usuário confirmou que os sites voltaram a abrir normalmente.

---

## Causa raiz

Cache DNS corrompido. O Windows armazena localmente o histórico de endereços visitados — quando esse cache fica desatualizado ou corrompido os sites não abrem mesmo com internet ativa.

---

## Lição aprendida

Quando sistemas internos funcionam mas sites não abrem — o problema é quase sempre no DNS. A diferença é que sistemas internos usam IPs diretos e não dependem de resolução DNS. Confirmar sempre com `ping 8.8.8.8` antes de `ping google.com`.
