# HelpDesk Operations — Matheus Grun

Repositório de operações práticas de suporte técnico — documentando procedimentos, casos resolvidos e base de conhecimento técnico construída ao longo da minha jornada de transição para a área de TI.

O objetivo é simular o ambiente operacional de um analista de suporte N1/N2, documentando cada atividade como faria em um helpdesk corporativo real.

## Estrutura

### Procedimentos
Documentação técnica de resolução dos problemas mais comuns no suporte N1/N2 — passo a passo, causa raiz e boas práticas.

### Casos Resolvidos
Registro de chamados simulados com descrição do problema, diagnóstico aplicado, solução e lição aprendida.

### Base de Conhecimento
Glossário técnico, definições e conceitos essenciais para o dia a dia do suporte técnico.

## Ambiente de Operação

Os casos registrados aqui são operados dentro do **CorpTech Manager** — ambiente corporativo simulado desenvolvido como projeto de portfolio.
